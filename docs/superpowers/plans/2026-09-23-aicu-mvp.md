# AICU MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the demo-critical vertical slice of AICU (shared patient record, nurse vitals entry, NEWS2 scoring, nurse→doctor escalation with acknowledgement) plus the remaining MVP features (handovers, orders→tasks, medication loop, audit log, BLE), in that order, on Flutter + Firebase.

**Architecture:** One shared Firestore-backed patient record with two role-specific Flutter views (nurse, doctor). Pure-Dart services (`lib/services/`) hold all scoring/generation logic and are unit-tested without Firebase. Thin repositories (`lib/repositories/`) wrap Firestore reads/writes and are tested against the Firebase Local Emulator Suite. Widgets consume repositories via `StreamBuilder`/`FutureBuilder`; no BLoC/Provider layer is introduced — Flutter's built-in `StreamBuilder` is sufficient for this scope.

**Tech Stack:** Flutter 3.41.6 / Dart 3.11.4, Firebase Auth, Cloud Firestore, Firebase Storage, Firebase Cloud Messaging (roadmap-only, see spec §3.1), Hive (local-only data), `mobile_scanner` (QR), `flutter_blue_plus` (BLE, last phase), `flutter_test` + `firebase_emulator_suite` for tests.

**Spec:** `docs/superpowers/specs/2026-09-23-aicu-mvp-design.md` — read this first. It has the full Firestore schema (§6), the NEWS2 chart with citation (§8), and six explicit stack-gap decisions (§3) that every task below assumes.

## Global Constraints

- Every Firestore field name and collection name matches spec §6 exactly — no renaming.
- No FCM push dependency in the demo-critical path (spec §3.1) — escalation delivery is a Firestore `snapshots()` listener.
- No voice input in this plan (spec §3.2) — structured forms only.
- No custom Hive↔Firestore sync engine (spec §3.3) — Firestore's built-in offline persistence only; Hive is for local-only, non-synced data.
- NEWS2 thresholds are copied verbatim from spec §8 (RCP NEWS2, Dec 2017) — never approximate a boundary.
- `flutter test` must pass before every commit; emulator-backed tests run via `firebase emulators:exec 'flutter test <path>'`.

### Day-to-day collaboration

- **Sync points, not constant coordination.** Two points where tracks
  actually need each other: (1) Foundation merging to `main` — nothing else
  starts before this; (2) Track A's Task 6 (Patient model) merging —
  Track B pings Track A when they need it rather than blocking on a fixed
  schedule.
- **Rebase onto `main` daily**, not just at track completion — Track A
  moves fastest and other branches drift stale quickly otherwise.
- **`firestore.rules` is the one shared file.** Track C (Task 23) doesn't
  touch it until Track A's Task 12 is on `main`; when it does, it's an
  append (new `match` blocks above the existing catch-all), not a rewrite,
  so the merge is mechanical.
- **PR review gate:** every PR must show `flutter test` passing (per Global
  Constraints) before merge — this is the thing that keeps three people
  editing a shared Firestore schema from silently breaking each other.
  Emulator-backed tests (repositories, rules) need `firebase emulators:exec`
  in CI or run locally before pushing; note in the PR description which
  tests were run.
- **A quick async standup** (chat message, not a meeting) covering "what
  I merged, what I'm starting, what I'm blocked on" is enough given how few
  real dependencies there are between tracks — most blocking is a one-time
  wait for a specific type to land, not ongoing coordination.

// lib/repositories/auth_repository.dart
import 'package:cloud_firestore/cloud_firestore.dart';
import 'package:firebase_auth/firebase_auth.dart';
import 'package:aicu/models/app_user.dart';

class AuthRepository {
  final FirebaseAuth auth;
  final FirebaseFirestore firestore;
  AuthRepository({required this.auth, required this.firestore});

  Future<AppUser> signIn(String email, String password) async {
    final credential = await auth.signInWithEmailAndPassword(
      email: email,
      password: password,
    );
    final uid = credential.user!.uid;
    final doc = await firestore.collection('users').doc(uid).get();
    return AppUser.fromMap(uid, doc.data()!);
  }

  Stream<String?> currentUserRole() {
    final uid = auth.currentUser?.uid;
    if (uid == null) return Stream.value(null);
    return firestore
        .collection('users')
        .doc(uid)
        .snapshots()
        .map((doc) => doc.data()?['role'] as String?);
  }
}
```

// lib/services/news2_engine.dart
import 'package:aicu/models/vitals_reading.dart';

enum News2Band { none, low, medium, high }

class News2Result {
  final int aggregate;
  final News2Band band;
  final bool redFlag;
  const News2Result({required this.aggregate, required this.band, required this.redFlag});
}

class News2Engine {
  static News2Result score(VitalsReading v) {
    final scores = <int>[
      _respirationScore(v.respirationRate),
      _spo2Score(v),
      _bpScore(v.systolicBp),
      _pulseScore(v.pulse),
      _consciousnessScore(v.consciousness),
      _temperatureScore(v.temperature),
    ];
    final oxygenScore = v.onSupplementalOxygen ? 2 : 0;
    final aggregate = scores.fold(0, (a, b) => a + b) + oxygenScore;
    final redFlag = scores.any((s) => s == 3);

    News2Band band;
    if (aggregate >= 7) {
      band = News2Band.high;
    } else if (aggregate >= 5) {
      band = News2Band.medium;
    } else if (aggregate >= 1) {
      band = News2Band.low;
    } else {
      band = News2Band.none;
    }
    return News2Result(aggregate: aggregate, band: band, redFlag: redFlag);
  }

  static int _respirationScore(int rr) {
    if (rr >= 25) return 3;
    if (rr >= 21) return 2;
    if (rr >= 18) return 0;
    if (rr >= 12) return 0;
    if (rr >= 9) return 1;
    return 3; // <=8
  }

  static int _spo2Score(VitalsReading v) {
    if (v.spo2Scale == SpoScale.scale1) {
      if (v.spo2 >= 96) return 0;
      if (v.spo2 >= 94) return 1;
      if (v.spo2 >= 92) return 2;
      return 3; // <=91
    }
    // Scale 2 (hypercapnic respiratory failure, target 88-92)
    if (v.onSupplementalOxygen) {
      if (v.spo2 >= 97) return 3;
      if (v.spo2 >= 95) return 2;
      if (v.spo2 >= 93) return 1;
    }
    if (v.spo2 >= 93) return 0; // >=93 on air
    if (v.spo2 >= 88) return 0;
    if (v.spo2 >= 86) return 1;
    if (v.spo2 >= 84) return 2;
    return 3; // <=83
  }

  static int _bpScore(int sbp) {
    if (sbp >= 220) return 3;
    if (sbp >= 111) return 0;
    if (sbp >= 101) return 1;
    if (sbp >= 91) return 2;
    return 3; // <=90
  }

  static int _pulseScore(int pulse) {
    if (pulse >= 131) return 3;
    if (pulse >= 121) return 2;
    if (pulse >= 91) return 1;
    if (pulse >= 51) return 0;
    if (pulse >= 41) return 1;
    return 3; // <=40
  }

  static int _consciousnessScore(Consciousness c) =>
      c == Consciousness.alert ? 0 : 3;

  static int _temperatureScore(double t) {
    if (t >= 39.1) return 2;
    if (t >= 38.1) return 1;
    if (t >= 36.1) return 0;
    if (t >= 35.1) return 1;
    return 3; // <=35.0
  }
}

class PatientRepository {
  final FirebaseFirestore firestore;
  PatientRepository({required this.firestore});

  Future<Patient?> lookupByQr(String qrPayload) async {
    final doc = await firestore.collection('patients').doc(qrPayload).get();
    if (!doc.exists) return null;
    return Patient.fromMap(doc.id, doc.data()!);

    if (reading.temperature >= 38.1 || reading.temperature <= 36.0) {
      abnormal.add('temperature ${reading.temperature}°C');
    }

    final recommendation = switch (result.band) {
      News2Band.high => 'Requires emergency assessment by a critical care team now.',
      News2Band.medium => 'Requires urgent clinician review within the hour.',
      News2Band.low => result.redFlag
          ? 'Single-parameter red score — requires urgent review regardless of aggregate.'
          : 'Continue routine monitoring per ward protocol.',
      News2Band.none => 'Continue routine monitoring.',
    };

      situation: '${patient.fullName}, NEWS2 score ${result.aggregate} (${result.band.name}).',
      background: 'Diagnosis: ${patient.diagnosis}. Allergies: ${patient.allergies.join(', ')}.',

// add to lib/repositories/escalation_repository.dart, inside EscalationRepository
Future<int> acknowledge(String escalationId, String acknowledgedBy) async {
  final ref = firestore.collection('escalations').doc(escalationId);
  final doc = await ref.get();
  final raisedAt = doc.data()!['raisedAt'];
  final raisedAtTime = raisedAt is DateTime ? raisedAt : DateTime.now();
  final now = DateTime.now();
  final responseTimeSeconds = now.difference(raisedAtTime).inSeconds.clamp(0, 1 << 31);

  await ref.update({
    'acknowledgedBy': acknowledgedBy,
    'acknowledgedAt': FieldValue.serverTimestamp(),
    'responseTimeSeconds': responseTimeSeconds,
  });
  return responseTimeSeconds;
}

// lib/services/handover_diff.dart
class HandoverDiff {
  static List<String> compute(Map<String, dynamic>? previous, Map<String, dynamic> current) {
    final prev = previous ?? const {};
    final changes = <String>[];
    for (final entry in current.entries) {
      if (!prev.containsKey(entry.key)) {
        changes.add('${entry.key} added: ${entry.value}');
      } else if (prev[entry.key] != entry.value) {
        changes.add('${entry.key} changed from ${prev[entry.key]} to ${entry.value}');
      }
    }
    return changes;
  }
}

// lib/services/missing_data_checker.dart
class MissingDataChecker {
  static List<String> check({
    required DateTime? lastVitalsAt,
    required DateTime now,
    Duration staleAfter = const Duration(hours: 4),
  }) {
    if (lastVitalsAt == null) {
      return ['No vitals have been recorded for this patient.'];
    }
    if (now.difference(lastVitalsAt) > staleAfter) {
      return ['No vitals recorded in the last ${staleAfter.inHours} hours (last: $lastVitalsAt).'];
    }
    return const [];
  }
}

enum TaskStatus { pending, done, overdue }

class TaskStatusCalculator {
  static TaskStatus statusFor({required DateTime dueAt, required DateTime now, required bool isDone}) {
    if (isDone) return TaskStatus.done;
    return now.isAfter(dueAt) ? TaskStatus.overdue : TaskStatus.pending;
  }

import 'package:cloud_firestore/cloud_firestore.dart';

class OrderRepository {
  final FirebaseFirestore firestore;
  OrderRepository({required this.firestore});

  Future<String> createOrder({
    required String patientId,
    required String wardId,
    required String createdBy,
    required String description,
    required DateTime dueAt,
  }) async {
    final taskRef = firestore.collection('tasks').doc();
    final orderRef = firestore.collection('orders').doc();

    await taskRef.set({
      'patientId': patientId,
      'wardId': wardId,
      'sourceOrderId': orderRef.id,
      'description': description,
      'dueAt': dueAt,
      'status': 'pending',
      'completedBy': null,
      'completedAt': null,
    });
    await orderRef.set({
      'patientId': patientId,
      'wardId': wardId,
      'createdBy': createdBy,
      'createdAt': FieldValue.serverTimestamp(),
      'description': description,
      'dueAt': dueAt,
      'taskId': taskRef.id,
    });
    return orderRef.id;
  }

  Stream<List<Map<String, dynamic>>> watchTasks(String wardId) {
    return firestore
        .collection('tasks')
        .where('wardId', isEqualTo: wardId)
        .snapshots()
        .map((snap) => snap.docs.map((d) => {'id': d.id, ...d.data()}).toList());

// lib/repositories/event_repository.dart
import 'package:cloud_firestore/cloud_firestore.dart';

class EventRepository {
  final FirebaseFirestore firestore;
  EventRepository({required this.firestore});

  Future<void> log({
    required String patientId,
    required String wardId,
    required String actorId,
    required String action,
    required String refCollection,
    required String refId,
  }) {
    return firestore.collection('events').add({
      'patientId': patientId,
      'wardId': wardId,
      'actorId': actorId,
      'action': action,
      'refCollection': refCollection,
      'refId': refId,
      'occurredAt': FieldValue.serverTimestamp(),
    });
  }

  Stream<List<Map<String, dynamic>>> watchTimeline(String patientId) {
    return firestore
        .collection('events')
        .where('patientId', isEqualTo: patientId)
        .orderBy('occurredAt')
        .snapshots()
        .map((snap) => snap.docs.map((d) => d.data()).toList());
  }
}
```

// lib/services/simulated_vitals_feed.dart
import 'package:aicu/models/vitals_reading.dart';

class SimulatedVitalsFeed {
  static List<VitalsReading> deteriorating({required VitalsReading start, required int steps}) {
    final respirationStep = ((28 - start.respirationRate) / (steps - 1)).ceil();
    final spo2Step = ((start.spo2 - 89) / (steps - 1)).ceil();

    return List.generate(steps, (i) {
      final rr = (start.respirationRate + respirationStep * i).clamp(start.respirationRate, 30);
      final spo2 = (start.spo2 - spo2Step * i).clamp(88, start.spo2);
      return VitalsReading(
        respirationRate: rr,
        spo2: spo2,
        spo2Scale: start.spo2Scale,
        onSupplementalOxygen: start.onSupplementalOxygen,
        systolicBp: start.systolicBp,
        pulse: start.pulse,
        consciousness: start.consciousness,
        temperature: start.temperature,
      );
    });
  }
}

// lib/services/ble_vitals_parser.dart
import 'package:aicu/models/vitals_reading.dart';

class BleVitalsParser {
  // ponytail: placeholder 4-byte layout (rr, spo2, pulse, reserved) until the
  // chosen wearable's real GATT characteristic spec is available; swap the
  // byte offsets here once it is — nothing downstream depends on this layout.
  static VitalsReading? parse(List<int> bytes) {
    if (bytes.length < 4) return null;
    return VitalsReading(
      respirationRate: bytes[0],
      spo2: bytes[1],
      spo2Scale: SpoScale.scale1,
      onSupplementalOxygen: false,
      systolicBp: 120, // not carried by this wearable; nurse confirms/edits before saving
      pulse: bytes[2],
      consciousness: Consciousness.alert,
      temperature: 36.5, // not carried by this wearable; nurse confirms/edits before saving
    );
  }
}

  const BlePairingScreen({super.key, required this.onReading});

  Future<void> _connectAndListen(BluetoothDevice device, Guid characteristicUuid) async {
    await device.connect();
    final services = await device.discoverServices();
    for (final service in services) {
      for (final characteristic in service.characteristics) {
        if (characteristic.uuid == characteristicUuid) {
          await characteristic.setNotifyValue(true);
          characteristic.lastValueStream.listen((bytes) {
            final reading = BleVitalsParser.parse(bytes);
            if (reading != null) onReading(reading);
          });
        }
      }
    }
